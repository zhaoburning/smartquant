# 智能股票量化交易系统 - 需求设计文档

## 1. 项目概述

### 1.1 项目名称
**SmartQuant** - A股智能量化交易系统

### 1.2 项目愿景
打造一款轻量级、智能化的A股量化交易工具，每天自动分析市场数据，筛选优质股票，为投资者提供科学的交易决策辅助。

### 1.3 核心价值
- 🤖 **自动化** - 每日自动运行策略，智能筛选股票
- 📊 **数据驱动** - 基于历史数据回测，科学验证策略有效性
- 🎯 **风险可控** - 模拟交易环境，实盘前充分验证
- 💡 **智能推荐** - 每日推送优质股票建议，省时省力

## 3. 详细功能需求

### 3.1 数据层功能

#### 3.1.1 数据源
- **股票列表**：沪深两市所有股票基本信息
- **实时行情**：开盘价、收盘价、最高价、最低价、成交量、成交额
- **K线数据**：日线、周线、月线，支持复权处理
- **财务数据**：市盈率(PE)、市净率(PB)、市值、净利润、营收等
- **技术指标**：MACD、KDJ、RSI、布林带、均线系统

#### 3.1.2 数据存储
- 使用 SQLite 轻量级数据库存储历史数据
- 支持数据增量更新
- 数据保留最近 5 年的日线数据

#### 3.1.3 数据接口
```python
# 数据层核心接口设计
class DataSource:
    def get_stock_list() -> DataFrame          # 获取股票列表
    def get_realtime_quote(stock_code) -> Dict  # 获取实时行情
    def get_historical_data(stock_code, days) -> DataFrame  # 获取历史K线
    def get_financial_data(stock_code) -> Dict  # 获取财务数据
```

### 3.2 策略引擎功能

#### 3.2.1 技术指标库
| 指标名称 | 说明 | 用途 |
|---------|------|------|
| MACD | 指数平滑异同移动平均线 | 判断趋势方向和动量 |
| KDJ | 随机指标 | 超买超卖判断 |
| RSI | 相对强弱指数 | 衡量价格涨跌强度 |
| BOLL | 布林带 | 判断股价波动范围 |
| MA | 移动平均线 | 趋势判断与支撑阻力 |
| VOL | 成交量分析 | 确认趋势有效性 |

#### 3.2.2 选股策略模板

**策略1：趋势动量策略**
```
选股条件：
1. 20日均线 > 60日均线（上升趋势）
2. MACD > 0（DIF和DEA都大于0）
3. 20日涨幅 > 5%
4. 成交量较20日均量放大1.5倍以上
5. 市值在50亿-500亿之间
```

**策略2：价值成长策略**
```
选股条件：
1. PE在15-30之间
2. PB < 3
3. 净利润同比增长率 > 15%
4. 营收同比增长率 > 10%
5. 股价在合理估值区间
```

**策略3：技术突破策略**
```
选股条件：
1. 股价突破20日最高价
2. 成交量突破20日均量2倍
3. 涨幅在3%-8%之间（不过于追高）
4. RSI < 70（未超买）
5. 流通市值 < 100亿
```

#### 3.2.3 策略管理
```python
class Strategy:
    def select_stocks() -> List[Stock]      # 选股方法
    def calculate_indicators() -> Dict       # 计算技术指标
```

- **推荐数量**：每次推荐3-5只股票
- **更新频率**：每天更新股票池

## 6. 风险控制

### 6.1 仓位管理
- 单只股票最大仓位：20%
- 单日最大亏损限额：5%
- 总仓位控制：不超过80%

### 6.2 止损机制
- 固定止损：亏损8%自动止损
- 移动止损：回撤超过5%触发
- 时间止损：持仓超过20个交易日无明显收益

### 6.3 风控规则
```python
class RiskControl:
    MAX_POSITION_RATIO = 0.2      # 单股最大仓位20%
    MAX_TOTAL_POSITION = 0.8     # 总仓位不超过80%
    STOP_LOSS_PERCENT = 0.08      # 止损线8%
    MAX_DAILY_LOSS = 0.05         # 单日最大亏损5%
    MAX_HOLDING_DAYS = 20         # 最大持仓天数
```

## 10. 注意事项与免责声明

### ⚠️ 重要提示

1. **模拟交易≠实盘**：本系统所有交易均为模拟交易，不涉及真实资金
2. **历史业绩不代表未来**：策略过往回测结果不代表未来收益
3. **市场风险**：股票投资存在风险，盈亏自负
4. **数据延迟**：免费数据源可能存在延迟，不适合高频交易
5. **合规要求**：本系统仅供学习研究使用，请遵守相关法律法规
