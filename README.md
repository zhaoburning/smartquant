# SmartQuant - A股智能量化交易系统

基于Python的A股智能量化交易系统，包含数据获取、策略回测、智能推荐和模拟交易功能。

## 功能特点

- 📊 **数据采集**: 使用akshare获取A股历史数据和实时行情
- 🧠 **策略引擎**: 三种选股策略（趋势动量、价值成长、技术突破）
- 📈 **技术指标**: MACD、KDJ、RSI、布林带等常用技术指标
- 🔍 **智能选股**: 每日自动筛选优质股票，综合评分推荐
- 🧪 **回测系统**: 历史回测，验证策略有效性
- 🎮 **模拟交易**: 虚拟资金，真实规则模拟交易
- 🌐 **Web接口**: RESTful API，便于前端对接

## 项目结构

```
smartquant/
├── config/              # 配置文件
├── data/                # 数据层
├── strategies/          # 策略模块
├── analysis/            # 分析和回测
├── trading/             # 交易模块
├── recommendation/      # 推荐系统
├── web/                 # Web服务
├── tests/               # 测试
├── main.py              # 主程序入口
└── requirements.txt     # 依赖包
```

## 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 运行主程序

```bash
python main.py
```

这将初始化系统，更新股票列表，并生成今日推荐。

### 3. 启动Web服务器

```bash
python -m web.app
```

访问 http://localhost:5000/api/health 确认服务正常。

## API接口

### 健康检查
```
GET /api/health
```

### 获取今日推荐
```
GET /api/recommendations
```

### 生成推荐
```
POST /api/recommendations/generate
```

### 查询账户
```
GET /api/account
```

### 获取交易历史
```
GET /api/account/trades
```

### 查询个股信息
```
GET /api/stock/<stock_code>
```

## 策略说明

### 1. 趋势动量策略
- 20日均线上穿60日均线
- MACD > 0
- 20日涨幅适中且放量
- 适合追踪强势股

### 2. 价值成长策略
- PE、PB处于合理区间
- 营收、利润有增长
- KDJ低位金叉
- 适合稳健型投资者

### 3. 技术突破策略
- 价格突破20日新高
- 成交量放大2倍以上
- 未超买
- 适合捕捉突破性行情
