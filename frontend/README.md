# SmartQuant - A股智能量化交易系统

一个基于 React 的 A 股智能量化交易系统前端界面。

## 功能特点

- 📊 股票推荐 - 基于量化策略的智能股票推荐
- 💹 模拟交易 - 支持买卖模拟交易
- 📈 技术分析 - K线图和历史数据分析
- 💰 账户管理 - 投资组合和交易历史

## 快速开始

```bash
# 安装依赖
npm install

# 开发模式
npm run dev

# 构建生产版本
npm run build
```

## 部署

本项目已配置支持 GitHub Pages 部署。

### 部署到 GitHub Pages

1. 将代码推送到 GitHub 仓库
2. 在仓库设置中启用 GitHub Pages
3. 选择 `gh-pages` 分支作为源

访问地址：`https://zhaoburning.github.io/smartquant`

## 技术栈
